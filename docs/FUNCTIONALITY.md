# Функционал оригинального Omni → наша версия

Источник: `omni.top-academy.ru` (AngularJS + Yii).

## Реализовано в Omni Fast (MVP)

| Модуль | Оригинал | У нас |
|--------|----------|-------|
| Логин / восстановление | `/auth/login`, restore | Логин + сессия 30 дней |
| Расписание | `/schedule/get-schedule` | Экран «Пары», дни недели |
| Присутствующие (ядро) | `/presents/*` | Экран пары: был/опоздал/не был, КР/урок, тема, «все были» |
| Журнал классной работы | `/classwork/*` | Просмотр по группе/предмету |
| Смена преподавателя | `/auth/change-user` | Профиль (для админ-аккаунтов) |
| Кэш + очередь + re-check 2ч | — | Worker/D1/cron |
| PWA | нет | да |

## В очереди на перенос

- Домашние / лабы (`homework`, `presents/new-homework`, материалы)
- Экзамены / курсовые / диплом
- Группы (сводная сетка посещений)
- Студенты, комментарии, review queue
- Трафик / заявки
- Задачи преподавателя
- Новости / сигналы
- Досье / портфолио / отчёты
- Профиль (смена пароля)
- Method package / bind (методисты)
